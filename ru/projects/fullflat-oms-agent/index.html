AI-агент для системы управления заказами

Автоматизировала создание визуализаций заказа для клиента — с реальными образцами материалов из каталога, чтобы показать точно то, что клиент купил, ещё до доставки

Роль

Архитектор систем и AI-интеграции

Компания

FullFlat LLC

Локация

ОАЭ

Год

2026

Технологии

Airtable OpenAI AI Image Generation

Задача

У клиентов, заказывающих несколько предметов, не было способа увидеть заранее, как их выбор цветов и материалов будет смотреться вместе, до доставки. Комбинации цветов и материалов дивана, кровати, прикроватных столиков и декоративных предметов невозможно было представить заранее, что создавало неопределённость и иногда недовольство после покупки.

Обзор

AI-агент, встроенный в систему управления заказами FullFlat на Airtable, автоматизирует создание визуалов для клиента. Каждый заказ получает визуализацию с реальными образцами материалов из каталога, чтобы клиент видел точно то, что получит, ещё до отгрузки.

Решение

Построила AI-агента как автоматизацию Airtable на базе GPT Image, генерирующую визуализации мебели по запросу — либо для отдельного товара из каталога, либо для целого заказа клиента.

Визуализатор заказа и товара

Этот агент генерирует визуализации раскладки мебели, беря образцы из библиотеки материалов, привязанной к каждой вариации товара — на примере выше: диван, кровать, прикроватные столики, лампа и тумбочки в одной раскладке с доступными вариантами отделки. Работает двумя способами: по отдельному товару из каталога, чтобы показать клиенту варианты материала и цвета для этой позиции, или по полному заказу клиента, объединяя все купленные позиции в одну согласованную визуализацию с точно выбранной отделкой.

При запуске по заказу агент берёт запись вариации каждой позиции заказа, извлекает связанные материалы из общей библиотеки материалов и собирает изображение раскладки, показывающее весь заказ вместе — вместо того, чтобы клиент представлял, как пять отдельно сфотографированных предметов будут смотреться рядом в выбранных цветах. Готовая визуализация отправляется клиенту напрямую по email или WhatsApp, давая ему чёткое превью заказа до отгрузки.

У оператора также есть возможность добавлять кастомные товары, не входящие в каталог, вставляя референсные изображения напрямую. Это покрывает редкие продажи товаров вне каталога по запросу клиента, так что визуализация остаётся точной, даже если заказ включает то, что FullFlat обычно не продаёт.

Внутри редактора мудборда

На практике оператор работает из представления позиций заказа и отмечает, какие товары должны попасть в визуализацию, переключателем-звёздочкой в колонке «Добавить в мудборд» — это полезно для заказов, где в рендер должны попасть только некоторые позиции (например, базовый пакет), а допы или неопределённые позиции остаются за кадром.

При переходе в редактор мудборда заказа показываются изображения выбранных товаров, автоматически подтянутые из карточки каждой позиции в каталоге, вместе со сгенерированным мудбордом и подобранными образцами материалов после того, как агент отработал.

Под капотом автоматизация «Create Moodboards» запускается по клику на кнопку: берёт изображения выбранных товаров как вход, отправляет их в модель генерации изображений (GPT Image, низкая точность, альбомная ориентация 1536×1024) с промптом, инструктирующим собрать дизайнерский коллаж-мудборд, используя входные изображения как есть без изменений, затем записывает результат обратно в поле вложений Mood Boards записи через следующий шаг скрипта.

Интеграция и процесс

Агент работает как автоматизация Airtable внутри системы управления заказами, запускается по запросу кликом по кнопке. Никакой внешней инфраструктуры, никаких серверов — только нативная автоматизация Airtable в связке с вызовами API GPT Image. Визуализатор отправляет результат напрямую клиенту, замыкая цикл между подтверждением заказа и доставкой чётким визуальным превью.

Результат

  • Визуализации заказа отправляются клиентам напрямую — снижая неопределённость перед доставкой по комбинациям материалов и цветов
  • Работает и для отдельных товаров, и для полных заказов одним и тем же агентом, без отдельного инструментария
  • Реальные образцы материалов из той же библиотеки, что привязана к каждой вариации товара — не общие рендеры
  • Выборочное включение через переключатель-звёздочку даёт оператору контроль над тем, какие позиции заказа попадают в рендер
  • Поддерживает кастомные товары вне каталога через референсные изображения, загруженные оператором, для разовых продаж по запросу клиента
